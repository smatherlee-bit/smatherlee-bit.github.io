Privacy policy

Last updated: 12 November 2026

Mat-Nest Pathfinder ("the app") is a personal tool used only by its owner's household.

What data the app uses

With the owner's permission, the app reads Gmail messages that carry one specific label chosen by the owner (travel booking confirmations). It uses the read-only Gmail scope and cannot send, edit or delete email.

How the data is used

Booking details (dates, places, times, providers) are extracted and saved to the owner's own self-hosted trip planner on the owner's home server.

Sharing

Data is not sold, rented or shared with anyone. It is not used for advertising and is not used to train AI models. It does not leave the owner's own systems except for the request to Google to read the labelled messages.

Google API data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and deletion

Data is stored encrypted on the owner's home server. Access can be revoked at any time at myaccount.google.com/permissions, and the owner can delete stored data at any time.

Contact

Questions: use the support email shown on the app's Google sign-in screen.
